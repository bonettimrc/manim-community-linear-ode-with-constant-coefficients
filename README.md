# Manim Community Linear ODE with Constant Coefficients

This is a science communication project, that uses the [manim community](https://www.manim.community/) python library to adapt on video a basic understanding and analysis of linear ordinary differential equations with constant coefficients.
I used my high school knowledge and the book [An Elementary Treatise on Differential Equations](https://archive.org/details/elementarytreati032501mbp) by H. T. H. Piaggio as the source material
